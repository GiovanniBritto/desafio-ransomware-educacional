# Publicação no GitHub e entrega na DIO

## Publicar este projeto

1. Extraia o ZIP em uma nova pasta.
2. Entre na sua conta do GitHub e crie um novo repositório público chamado `desafio-ransomware-educacional`.
3. Como o pacote já contém README, `.gitignore` e licença, crie o repositório vazio.
4. Na página inicial do repositório, use a opção de enviar um arquivo existente.
5. Entre na pasta extraída onde estão `README.md`, `encrypter.py` e `decrypter.py`. Arraste seu conteúdo, incluindo as pastas, para a área de upload.
6. Use a mensagem de commit `Adiciona laboratorio educacional de criptografia em Python` e confirme o envio.
7. Confira se o README aparece na página principal e se as pastas `laboratorio`, `tests` e `docs` estão presentes.

O ZIP preparado contém somente o material de entrega. Se você executar o laboratório antes de publicar, mantenha `.venv/` e `laboratorio/gerados/` fora do upload. A pasta de resultados contém a chave de demonstração. O `.gitignore` orienta o Git na linha de comando, mas não filtra os arquivos que você selecionar manualmente no navegador.

## Revisar antes da submissão

Assista às aulas, execute os scripts e os testes no seu ambiente e personalize o README com o que aprendeu. A implementação é um laboratório limitado a um arquivo fictício, com preservação do original; mantenha essa descrição na entrega.

## Preencher a tela da DIO

Em **Repositório do projeto**, cole o endereço real do novo repositório. Se você usar o nome sugerido na conta já utilizada nesta conversa, o endereço terá este formato:

```text
https://github.com/GiovanniBritto/desafio-ransomware-educacional
```

Esse endereço é uma sugestão; o repositório ainda precisa ser criado e publicado.

Em **Descrição**, após revisar e executar o projeto, você pode usar:

> Laboratório educacional em Python inspirado no desafio de ransomware. Os scripts encrypter.py e decrypter.py criptografam e recuperam uma cópia de um arquivo fictício usando Fernet, preservando o original. O projeto inclui verificação de integridade, tratamento de erros, testes automatizados e documentação técnica. A implementação é limitada ao exemplo fornecido.

Leia os termos apresentados pela DIO e, se concordar e tiver concluído os requisitos, marque a caixa e envie o projeto.

## Situação deste pacote

Os arquivos foram preparados e validados localmente. Nenhum novo repositório foi criado, nenhuma submissão foi enviada e não há página web hospedada para este projeto. O funcionamento principal é pelos scripts Python.
